# client-js

Папка для общих JavaScript-модулей фронтенда, которые можно подключать к HTML-страницам.

Структура:
- `client-js/` — исходники модулей
  - `modules/` — переиспользуемые модули
  - `vendor/` — сторонние библиотеки (если не подключаете CDN)

Можно компилировать в `server/public/js/` при сборке.
